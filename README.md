## Features

- 🎲 **3D Physics** — Realistic dice rolling powered by Rapier physics engine
- 🌐 **Multiplayer** — Real-time P2P multiplayer via PeerJS (share a link or QR code)
- 🎯 **Dice Locking** — Lock individual dice between rolls (like Yahtzee)
- 💰 **Betting System** — Set bet amounts and multipliers; scores tracked live
- 🎨 **Customization** — 2 board models, 10 material variants, 2 dice models
- 👥 **Live Cursors** — See other players' cursor positions in real time
- 📱 **PWA** — Installable as a Progressive Web App

## Tech Stack

| | |

| Physics | Rapier (`@react-three/rapier`) |
| Multiplayer | PeerJS (WebRTC P2P) |
| State | Zustand |
